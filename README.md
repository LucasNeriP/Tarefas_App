# Tarefas App

Aplicação para organizar tarefas do dia a dia, desenvolvida para praticar React e a integração com um backend em Node.js e MySQL.

## Funcionalidades

- Cadastro e login de usuários.
- Criação e exclusão de tarefas.
- Marcação de tarefas como concluídas ou favoritas.
- Filtros para visualizar todas, concluídas e favoritas.
- Tarefas salvas no banco e separadas por usuário.
- Interface adaptada para computador e celular.

## Tecnologias

React, Vite, CSS, Node.js, Express, MySQL e Argon2 para proteção das senhas.
